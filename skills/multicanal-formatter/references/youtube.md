# YouTube — gramática do canal

No YouTube o conteúdo é o **vídeo mais longo** (3–12 min para conteúdo educativo; Shorts seguem a lógica do TikTok — ver `tiktok.md`). O sucesso depende de três coisas, nesta ordem: **título + thumbnail** (definem o clique), **primeiros 30 segundos** (definem a retenção inicial), e **estrutura** (define se a pessoa fica). A entrega é um pacote, não só o roteiro.

## Artefatos a entregar

1. **Título** — 3 a 5 opções, ≤60 caracteres, com a tensão/promessa clara.
2. **Thumbnail** — conceito visual: a frase de impacto (≤5 palavras) + direção (cor Horus, expressão, elemento gráfico).
3. **Roteiro** — introdução + corpo estruturado + fechamento.
4. **Capítulos** (timestamps) — para navegação e SEO.
5. **Descrição** — 2–3 linhas de resumo + capítulos + CTA.

## Estrutura do roteiro

```
[0–30s] INTRODUÇÃO / HOOK
  - Abra com a tensão ou a promessa, não com "fala galera, seja bem-vindo".
  - Diga em uma frase o que a pessoa vai sair sabendo.
  - Plante a curiosidade que só se resolve no fim (open loop).

[CORPO] em blocos nomeados (viram capítulos)
  - Cada bloco = um ponto da ideia, com sua âncora (dado/citação do documento).
  - Transições explícitas entre blocos ("agora que você entendeu X, falta Y").
  - Reforce a relevância prática em cada bloco ("na prática, isso significa...").

[FECHAMENTO]
  - Recapitule o insight central em uma frase.
  - CTA: inscrever-se / próximo vídeo / material complementar (sem captação jurídica).
  - Feche o open loop da introdução.
```

Quando o vídeo for de **oferta/posicionamento de marca** (não educativo puro), use a estrutura narrativa Kishōtenketsu da skill `vsl-kishotenketsu-creator` em vez desta — ela é desenhada para vender sem agressividade.

## Capítulos

Liste timestamps com títulos curtos e descritivos. Ex.:
```
00:00 O erro que custa o processo
01:10 O que a lei realmente diz
03:25 Como blindar o seu contrato
05:40 Resumo + próximo passo
```

## O que faz performar

- **Título e thumbnail são 80% do clique.** Trabalhe-os como peça principal, não como afterthought. Título promete; thumbnail intriga; juntos não podem ser clickbait que o vídeo não cumpre.
- **Retenção dos 30s.** Sem intro arrastada. Entregue valor (ou a promessa dele) imediatamente.
- **Estrutura nomeada.** Blocos claros = capítulos = retenção + SEO.

## Checklist (antes de entregar)

- [ ] 3–5 títulos ≤60 caracteres com tensão clara
- [ ] Conceito de thumbnail com frase ≤5 palavras + direção visual Horus
- [ ] Introdução entrega promessa em ≤30s, com open loop
- [ ] Corpo em blocos nomeados, cada um com sua âncora
- [ ] Capítulos com timestamps
