# Sistema Completo de Conteúdo para Vendas

Este skill fornece um sistema estruturado de 7 prompts sequenciais especificamente otimizado para criar conteúdo que vende.

## Os 7 Passos do Sistema de Vendas

O sistema funciona em 7 etapas que transformam visitantes em clientes:

1. **Diagnóstico de Vendas** - Identifica problemas e oportunidades
2. **Proposta de Valor** - Define o valor único oferecido
3. **Funil de Vendas** - Estrutura a jornada do cliente
4. **Mensagem que Converte** - Cria mensagem com alto poder de conversão
5. **Script de Vendas** - Desenvolve script efetivo
6. **Otimização de Conversão** - Melhora taxa de conversão
7. **Plano de Ação** - Cria plano executável

## Workflow Sequencial

### Etapa 1: Diagnóstico de Vendas

Identifique os problemas reais que seu produto/serviço resolve.

**Prompt:**
```
Qual é o diagnóstico de vendas para [PRODUTO/SERVIÇO]?
- Qual é o problema principal que resolvemos?
- Quem sofre com esse problema?
- Qual é o custo de não resolver?
- Por que as pessoas ainda não compraram?
```

**Saída esperada:** Diagnóstico claro dos problemas e oportunidades.

### Etapa 2: Proposta de Valor

Defina o que torna seu oferecimento único e valioso.

**Prompt:**
```
Qual é a proposta de valor para [PRODUTO/SERVIÇO]?
- O que oferecemos que ninguém mais oferece?
- Qual é o benefício principal?
- Como medimos o sucesso?
- Por que escolher a gente ao invés da concorrência?
```

**Saída esperada:** Proposta clara e diferenciada.

### Etapa 3: Funil de Vendas

Estruture a jornada do cliente do conhecimento à compra.

**Prompt:**
```
Qual é o funil de vendas para [PRODUTO/SERVIÇO]?
- Etapa 1 (Awareness): Como as pessoas descobrem?
- Etapa 2 (Consideration): Como demonstramos valor?
- Etapa 3 (Decision): Como facilitamos a compra?
- Etapa 4 (Retention): Como mantemos satisfeitos?
```

**Saída esperada:** Funil estruturado com ações em cada etapa.

### Etapa 4: Mensagem que Converte

Crie a mensagem central que vende.

**Prompt:**
```
Qual é a mensagem que converte para [PRODUTO/SERVIÇO]?
- Qual é o ganho principal?
- Qual é a urgência?
- Qual é a prova social?
- Qual é a chamada para ação?
```

**Saída esperada:** Mensagem com alto poder de conversão.

### Etapa 5: Script de Vendas

Desenvolva o script que os vendedores usarão.

**Prompt:**
```
Qual é o script de vendas para [PRODUTO/SERVIÇO]?
- Abertura (captar atenção)
- Descoberta (entender necessidade)
- Apresentação (mostrar solução)
- Objeção (responder dúvidas)
- Fechamento (pedir a venda)
```

**Saída esperada:** Script pronto para usar.

### Etapa 6: Otimização de Conversão

Identifique como melhorar a taxa de conversão.

**Prompt:**
```
Como otimizar a conversão para [PRODUTO/SERVIÇO]?
- Qual é a taxa de conversão atual?
- Onde estamos perdendo clientes?
- Como melhorar cada etapa?
- Qual é o teste mais importante?
```

**Saída esperada:** Plano de otimização com testes.

### Etapa 7: Plano de Ação

Crie um plano executável para implementar tudo.

**Prompt:**
```
Qual é o plano de ação para [PRODUTO/SERVIÇO]?
- Semana 1-2: Implementar diagnóstico
- Semana 3-4: Testar mensagem
- Semana 5-6: Treinar script
- Semana 7-8: Otimizar e escalar
```

**Saída esperada:** Plano com timeline e responsáveis.

## Aplicações Práticas

### Para Vendas B2B

Use o sistema para estruturar vendas complexas com ciclos longos.

### Para E-commerce

Adapte para otimizar funil de vendas online.

### Para Serviços

Use para criar script de consultoria e fechamento.

### Para Produtos Digitais

Aplique para criar funil de vendas automatizado.
