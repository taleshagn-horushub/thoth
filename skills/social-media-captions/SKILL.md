## Workflow de Criação por Plataforma

### Para Instagram

**Prompt:**
```
Crie uma legenda Instagram [TIPO] para [TEMA]:
- Máximo 2.200 caracteres
- Use line breaks para legibilidade
- Inclua 5-10 hashtags relevantes
- Emojis que reforçam a mensagem
- CTA clara (se aplicável)
```

### Para TikTok

**Prompt:**
```
Crie uma legenda TikTok [TIPO] para [TEMA]:
- Máximo 150 caracteres
- Hook na primeira linha
- Hashtags trending (3-5)
- Convide à ação (like, comentário, share)
```

### Para LinkedIn

**Prompt:**
```
Crie uma legenda LinkedIn [TIPO] para [TEMA]:
- Tom profissional mas acessível
- Máximo 3.000 caracteres
- Valor e aprendizado
- CTA profissional
- Hashtags relevantes
```

### Para Facebook

**Prompt:**
```
Crie uma legenda Facebook [TIPO] para [TEMA]:
- Conversacional
- Máximo 5.000 caracteres
- Convide à discussão
- Emojis moderados
- Link ou CTA clara
```

### Para Twitter/X

**Prompt:**
```
Crie uma legenda Twitter [TIPO] para [TEMA]:
- Máximo 280 caracteres
- Direto e impactante
- Hashtags relevantes (2-3)
- Link se necessário
```

## Elementos Críticos por Tipo

### Conversão
- Hook que captura atenção
- Benefício claro
- Urgência ou escassez
- CTA específica
- Link ou instruções

### Venda
- Problema identificado
- Solução apresentada
- Prova social
- Preço ou oferta
- CTA para compra

### Storytelling
- Personagem relatable
- Conflito ou desafio
- Resolução ou aprendizado
- Emoção genuína
- Reflexão final

### Engajamento
- Pergunta provocadora
- Convite à participação
- Respostas iniciais
- Comunidade ativa
- Reconhecimento de participantes

### Autoridade
- Insight valioso
- Dados ou evidência
- Experiência comprovada
- Aplicação prática
- Credibilidade

### Simples
- Mensagem clara
- Sem jargão
- Fácil de entender
- Direto ao ponto
- Sem floreios

### Viral
- Elemento surpreendente
- Relatable ou emocionante
- Fácil de compartilhar
- Trending ou relevante
- Memética
