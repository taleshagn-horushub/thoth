# Sistema de Estrutura de Conteúdo

Este skill fornece um framework estruturado com 7 elementos fundamentais que formam a base de qualquer conteúdo de qualidade.

## Os 7 Elementos Fundamentais

O sistema é baseado em 7 pilares que trabalham juntos para criar conteúdo coeso e impactante:

| Elemento | Função | Saída |
|----------|--------|-------|
| **O Núcleo** | Define a ideia central | Conceito unificador |
| **O Ângulo** | Explora perspectivas | Múltiplas abordagens |
| **A Pergunta** | Define o problema | Questão central |
| **A Tensão** | Cria interesse | Conflito/Oportunidade |
| **O Bastidor** | Fornece contexto | Histórico e situação |
| **O Insight** | Gera valor | Verdades profundas |
| **A Máquina de Ideias** | Escalabilidade | Sistema de geração |

## Workflow de Implementação

### Etapa 1: O Núcleo

Defina a ideia central que estrutura todo o conteúdo. Esta é a essência que tudo mais segue.

**Prompt:**
```
Qual é a ideia central (núcleo) que estrutura meu conteúdo sobre [TEMA]?
Defina em uma frase clara e memorável.
```

**Saída esperada:** Uma frase que resume a essência do tema.

### Etapa 2: O Ângulo

Explore múltiplas perspectivas para abordar o mesmo tema. Cada ângulo atrai um público diferente.

**Prompt:**
```
Defina 5 ângulos diferentes para abordar [NÚCLEO]:
Para cada um, explique como diferencia a abordagem e qual público atrai.
```

**Saída esperada:** 5 perspectivas únicas com públicos específicos.

### Etapa 3: A Pergunta

Defina a pergunta central que seu conteúdo responde. Isso cria clareza para o leitor.

**Prompt:**
```
Qual é a pergunta principal que meu conteúdo sobre [TEMA] responde?
Defina também 3 subperguntas relacionadas.
```

**Saída esperada:** Pergunta principal + 3 subperguntas.

### Etapa 4: A Tensão

Crie a tensão que faz o conteúdo ser interessante. Sem tensão, não há engajamento.

**Prompt:**
```
Qual é o problema, conflito ou oportunidade que cria tensão em [TEMA]?
Por que as pessoas se importam? Qual é a consequência de ignorar?
```

**Saída esperada:** Problema claramente definido e suas consequências.

### Etapa 5: O Bastidor

Desenvolva o contexto histórico e situacional. O bastidor justifica por que agora é importante.

**Prompt:**
```
Qual é o contexto histórico, a situação atual do mercado e a evolução de [TEMA]?
Por que agora é o momento certo para falar sobre isso?
```

**Saída esperada:** Contexto completo que justifica o conteúdo.

### Etapa 6: O Insight

Gere insights valiosos que diferenciam seu conteúdo. Insights são verdades profundas.

**Prompt:**
```
Quais são os 3 insights mais valiosos sobre [TEMA]?
Para cada um, explique por que é valioso e como muda a perspectiva.
```

**Saída esperada:** 3 insights com explicação de valor.

### Etapa 7: A Máquina de Ideias

Crie um sistema para gerar ideias continuamente. Isso torna o conteúdo escalável.

**Prompt:**
```
Como criar um sistema para gerar 50+ ideias de conteúdo baseado em [TEMA]?
Defina temas, formatos e ângulos que podem ser combinados.
```

**Saída esperada:** Sistema estruturado para gerar ideias.

## Aplicações Práticas

### Para Artigos

Use os 7 elementos para estruturar artigos profundos:
- Introdução: Apresente o Núcleo e a Pergunta
- Desenvolvimento: Explore os Ângulos e a Tensão
- Contexto: Desenvolva o Bastidor
- Valor: Apresente os Insights
- Conclusão: Ofereça a Máquina de Ideias para próximos passos

### Para Posts em Redes Sociais

Adapte os elementos para posts concisos:
- Núcleo: Mensagem principal
- Ângulo: Perspectiva única
- Pergunta: Engajamento (faça uma pergunta)
- Tensão: Crie urgência ou curiosidade
- Insight: Valor em poucas palavras

### Para Vídeos

Estruture vídeos com os 7 elementos:
- Abertura: Núcleo + Pergunta
- Desenvolvimento: Ângulos + Tensão
- Contexto: Bastidor
- Valor: Insights
- Encerramento: Máquina de Ideias (próximas ações)

### Para Campanhas

Integre os elementos em campanhas multi-canal:
- Cada ângulo pode ter uma campanha
- Cada insight pode gerar conteúdo
- A máquina de ideias alimenta 30+ dias de conteúdo

## Checklist de Qualidade

Antes de publicar, valide se seu conteúdo tem:

- ✓ Núcleo claro e memorável
- ✓ Ângulo único que diferencia
- ✓ Pergunta que ressoa com o público
- ✓ Tensão que cria interesse
- ✓ Bastidor que justifica
- ✓ Insights que agregam valor
- ✓ Sistema para escalar ideias

## Exemplos de Uso

**Exemplo 1: Artigo sobre Marketing Digital**
- Núcleo: "Marketing digital é sobre criar conexões, não apenas conversões"
- Ângulo: Perspectiva humanizada vs. técnica
- Pergunta: "Como criar conexões autênticas com seu público?"
- Tensão: Muitas marcas falham porque focam apenas em venda
- Bastidor: Evolução do marketing nos últimos 10 anos
- Insight: "Confiança é o novo ouro do marketing"
- Máquina de Ideias: 50+ posts sobre diferentes aspectos

**Exemplo 2: Post em Rede Social**
- Núcleo: "Produtividade não é sobre fazer mais, é sobre fazer melhor"
- Ângulo: Qualidade vs. quantidade
- Pergunta: "Você está ocupado ou produtivo?"
- Tensão: Síndrome do ocupado que não produz resultados
- Insight: "Descanso é produtivo"
