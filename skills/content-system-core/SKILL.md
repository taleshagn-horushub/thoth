# Sistema Completo de Conteúdo com IA

Este skill fornece um sistema estruturado de 7 prompts sequenciais para criar conteúdo estratégico e bem organizado usando inteligência artificial.

## Visão Geral do Processo

O sistema funciona em 7 etapas progressivas que constroem uma base sólida de conteúdo:

1. **O Núcleo** - Define a ideia central que estrutura todo o conteúdo
2. **O Ângulo** - Explora múltiplas perspectivas sobre o tema
3. **A Pergunta** - Define a pergunta que o conteúdo responde
4. **A Tensão** - Cria tensão que gera interesse e engajamento
5. **O Bastidor** - Desenvolve contexto e história por trás da ideia
6. **O Insight** - Gera insights valiosos e diferenciados
7. **A Máquina de Ideias** - Cria sistema para gerar ideias continuamente

## Como Usar

### Passo 1: Preparar o Contexto

Reúna informações sobre seu tema:
- Qual é o assunto principal?
- Quem é o público-alvo?
- Qual é o objetivo final (venda, educação, engajamento)?
- Qual é o contexto do mercado?

### Passo 2: Executar os 7 Prompts em Sequência

Cada prompt deve ser executado com a IA (ChatGPT, Claude, etc.) na ordem apresentada. Os resultados de cada etapa alimentam a próxima.

#### Prompt 1 - O Núcleo

```
Você é um estrategista de conteúdo. Analise o seguinte tema e defina seu núcleo central:

Tema: [INSIRA SEU TEMA]
Público-alvo: [INSIRA PÚBLICO]
Objetivo: [INSIRA OBJETIVO]

Estruture a resposta com:
- Núcleo (a ideia central em uma frase)
- Ângulo (como abordar o tema de forma única)
- Pergunta (qual pergunta o conteúdo responde)
- Tensão (qual problema ou conflito o conteúdo aborda)
- Bastidor (contexto histórico ou situacional)
- Insight (verdade profunda sobre o tema)
- Máquina de Ideias (como gerar ideias relacionadas)
```

#### Prompt 2 - O Ângulo

```
Com base no núcleo definido anteriormente, explore 5 ângulos diferentes para abordar o tema:

Núcleo: [RESULTADO DO PROMPT 1]

Para cada ângulo, forneça:
- Nome do ângulo
- Como ele diferencia sua abordagem
- Qual público específico ele atrai
- Qual é o ganho principal para esse público
```

#### Prompt 3 - A Pergunta

```
Defina a pergunta central que seu conteúdo responde:

Tema: [INSIRA TEMA]
Núcleo: [RESULTADO DO PROMPT 1]
Ângulo escolhido: [ESCOLHA UM ÂNGULO DO PROMPT 2]

Estruture:
- Pergunta principal
- 3 subperguntas relacionadas
- Por que essa pergunta importa
- Como o conteúdo responde cada uma
```

#### Prompt 4 - A Tensão

```
Crie a tensão que faz o conteúdo ser interessante:

Tema: [INSIRA TEMA]
Pergunta: [RESULTADO DO PROMPT 3]

Defina:
- O problema ou conflito central
- Por que as pessoas se importam
- Qual é a consequência de ignorar isso
- Como seu conteúdo resolve essa tensão
```

#### Prompt 5 - O Bastidor

```
Desenvolva o contexto e a história por trás da ideia:

Tema: [INSIRA TEMA]
Tensão: [RESULTADO DO PROMPT 4]

Crie:
- Contexto histórico relevante
- Situação atual do mercado
- Evolução do problema
- Por que agora é o momento certo
```

#### Prompt 6 - O Insight

```
Gere insights valiosos e diferenciados:

Tema: [INSIRA TEMA]
Bastidor: [RESULTADO DO PROMPT 5]

Forneça:
- 3 insights principais
- Por que cada um é valioso
- Como cada insight muda a perspectiva
- Dados ou evidências que suportam cada insight
```

#### Prompt 7 - A Máquina de Ideias

```
Crie um sistema para gerar ideias continuamente:

Tema: [INSIRA TEMA]
Insights: [RESULTADO DO PROMPT 6]

Estruture:
- 5 temas de conteúdo derivados
- 3 formatos diferentes para cada tema
- 2 ângulos alternativos para cada formato
- Como combinar esses elementos para criar 50+ ideias
```

## Saídas Esperadas

Após completar os 7 prompts, você terá:

- **Estrutura sólida** - Conteúdo bem fundamentado e organizado
- **Múltiplas perspectivas** - Vários ângulos para abordar o tema
- **Diferenciação** - Insights únicos que destacam seu conteúdo
- **Escalabilidade** - Sistema para gerar ideias continuamente
- **Engajamento** - Conteúdo que cria tensão e interesse

## Dicas de Implementação

1. **Customize os prompts** - Adapte os prompts ao seu contexto específico
2. **Itere** - Se um resultado não satisfazer, refine o prompt e tente novamente
3. **Combine resultados** - Use os outputs para criar conteúdo final (artigos, vídeos, posts)
4. **Reutilize** - A máquina de ideias gera material para meses de conteúdo
5. **Teste** - Valide qual ângulo e insight ressoam melhor com seu público

## Exemplos de Uso

- **Criar campanha de marketing** - Use para estruturar mensagem central e ângulos
- **Escrever artigo estratégico** - Use para definir pergunta, tensão e insights
- **Desenvolver produto** - Use para entender o núcleo e valor do produto
- **Planejar conteúdo mensal** - Use a máquina de ideias para gerar 50+ tópicos
